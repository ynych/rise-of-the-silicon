# 《硅基编年史》(Silicon Chronicle)

## 项目定位

一部关于人工智能时代的**非虚构写作项目**，通过整理真实的人物、事件、技术突破和组织变迁，构建一个完整的AI宇宙世界观，为后续小说创作提供扎实的素材基础。

---

## 核心设计理念

### 1. 三重时间线架构

```
史前时代 (2012-2022)    → 学术理想主义，技术奠基
    ↓
奇点临近 (2022-2030)    → 人才战争，地缘博弈，组织冲突
    ↓
AGI爆发  (2030-2040)    → 技术奇点，社会重构，人性考验
```

### 2. 叙事核心：技术 vs 人性

- **技术维度**：模型能力、架构创新、算力竞赛
- **人性维度**：理想主义 vs 商业现实，个人成长 vs 组织约束
- **冲突焦点**：开源 vs 闭源，速度 vs 安全，东方 vs 西方

### 3. 人物驱动

以**真实KOL**为原型，构建30位核心人物的恩怨情仇：
- 不是传记，而是**群像戏**
- 关注**选择时刻**：他们为什么离开、为什么留下、为什么背叛
- **失败者的尊严**：被组织抛弃的技术理想主义者

## 写作原则

### 1. 真实性原则
- 所有素材基于**公开报道、论文、访谈**
- 模糊处理敏感信息（人名、细节）但保持**事件内核真实**
- 标注信息来源，可查证

### 2. 多视角原则
- 同一事件，不同立场（CEO、技术负责人、普通员工）
- 避免单一叙事，呈现复杂性
- "没有赢家"的棋局视角

### 3. 结构性原则
- 时间线清晰，可追踪
- 人物关系图谱完整
- 技术演进逻辑自洽

### 4. 文学性原则
- 关注**细节**：深夜的推文、会议室的沉默、代码提交记录
- 关注**瞬间**：决定离职的那一刻、被架空的那一刻
- 关注**遗憾**：理想主义者的妥协与坚持

## 核心洞察（暂定）

### 1. 技术演进不是线性的
从2012年AlexNet到2026年AGI临近，技术突破往往来自"意外"：
- Transformer论文作者没人想到会如此成功
- DeepSeek的低成本训练是"被迫"的（芯片禁令）
- ChatGPT是"半成品"却引爆全球

### 2. 组织是创新的敌人
所有技术突破都来自"被遗忘的角落"：
- OpenAI早期"没人管"的GPT团队
- 阿里Qwen在达摩院角落野蛮生长
- 字节Seed最初只是一个小探索团队

但当组织壮大，管理介入，创新往往停滞：
- 阿里Qwen团队被拆分，核心人员离职
- OpenAI商业化后安全团队解散
- 字节Seed吴永辉入主后7位核心离开

### 3. 开源是技术理想主义者的武器
- 林俊旸用开源对抗组织商业化压力
- DeepSeek用开源打乱全球格局
- 开源不是技术选择，是**价值观选择**

### 4. 人才战争的本质是价值观战争
- 不是钱的问题（Anthropic创始人身家12亿仍全员在岗）
- 是**对AI未来的不同想象**
- 是**对组织文化的认同与否**
