# 信息来源标注规范

> 版本：v1.0 | 最后更新：2026-03-14

---

## 来源分级

| 标签 | 定义 | 可信度 | 视觉样式 |
|------|------|--------|----------|
| **[官方]** | 公司官方公告、财报、论文、博客 | 最高 | 正常文本 |
| **[权威媒体]** | Reuters, Bloomberg, CNBC, Nature, 财新, 晚点等 | 高 | 正常文本 |
| **[多方交叉验证]** | 3个以上独立信源确认 | 高 | 正常文本 |
| **[单一信源]** | 仅一家媒体报道，未经多方确认 | 中 | *斜体灰色* |
| **[推测]** | 基于公开信息的合理推断 | 低 | *斜体灰色* |
| **[待验证]** | 2025年后事件，或信息尚未完全确认 | 待确认 | **粗体红色** |

---

## 视觉区分标准

### [单一信源] 和 [推测] 内容

使用斜体和灰色进行视觉区分：

```markdown
<span style="color: #666; font-style: italic;">[单一信源]</span>

> 引语内容 <span style="color: #666; font-style: italic;">[单一信源]</span>
```

渲染效果：
> *引语内容* [单一信源]

### [待验证] 内容

使用粗体和警示色：

```markdown
**<span style="color: #d73a49;">[待验证]</span>** 事件描述
```

渲染效果：
**[待验证]** 事件描述

---

## 应用示例

### 示例1：单一信源引语

**原文**：
```markdown
据内部人士透露：[单一信源]
> "百度将进行大规模裁员。" [单一信源]
```

**修正后**：
```markdown
<span style="color: #666; font-style: italic;">[单一信源]</span> 据内部人士透露：
> "百度将进行大规模裁员。" <span style="color: #666; font-style: italic;">[单一信源]</span>
```

### 示例2：2025年后事件

**原文**：
```markdown
### 2025.06 —— AI上半场/下半场分界
**标志**：从"训练Scaling"转向"推理优化"
```

**修正后**：
```markdown
### 2025.06 —— AI上半场/下半场分界 **[待验证]**
**标志**：从"训练Scaling"转向"推理优化"
```

## 注意事项

1. **不要过度使用**：[单一信源]和[推测]只用于关键论断，普通事实陈述无需标注
2. **保持可读性**：视觉区分的目的是提醒读者，而非打断阅读
3. **定期更新**：当[单一信源]被多方验证后，升级为[多方交叉验证]
4. **2025+事件**：所有2025年后发生的事件（除DeepSeek-R1等已确认重大事件）应标注[待验证]
