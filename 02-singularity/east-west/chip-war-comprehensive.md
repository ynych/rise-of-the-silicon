# 芯片战争全景：美国禁令与国产替代

## 一、美国禁令时间线（2022-2026）

### 1.1 禁令三部曲

| 时间 | 事件 | 影响 |
|------|------|------|
| **2022年8月** | A100/H100被禁 | 英伟达失去高端市场 |
| **2023年10月** | A800/H800被禁 | "阉割版"也无法出口 |
| **2025年4月** | H20被禁 | 英伟达彻底退出中国高端市场 |
| **2025年5月** | 全球禁用昇腾 | 美国宣布在世界任何地方使用华为昇腾芯片都属违规 |
| **2025年7月** | H20解禁 | 特朗普政府恢复出口，但需审查 |
| **2026年2月** | H200审批僵局 | 国务院推动更严格限制 |

### 1.2 H20：妥协的产物

**技术参数**：
- 峰值算力：仅H100的15%
- 内存带宽：4TB/s（H100的约一半）
- 互联速度：降至H100的1/15

**黄仁勋的评价**：
> "H20非常适合中国市场，客户非常想要。"

**现实**：
- 专为中国市场设计，海外无竞争力
- 2025年4月禁令导致55亿美元库存损失
- 7月解禁被视为"清库存"策略

## 二、黄仁勋的困境与博弈

### 2.1 三次访华

| 时间 | 背景 | 目标 |
|------|------|------|
| **2025年1月** | 拜登卸任前一周 | 传递"中国市场不可替代"信号 |
| **2025年4月** | H20被禁后48小时 | 紧急救火，安抚客户 |
| **2025年7月** | H20解禁后 | 庆祝市值破4万亿美元 |

### 2.2 海湖庄园会谈

**2025年7月10日**：
- 黄仁勋与特朗普闭门会面
- 核心论点：放弃中国=将市场让给华为
- 结果：H20出口获批

### 2.3 损失统计

| 指标 | 数据 |
|------|------|
| 市场份额 | 95% → 50% → 0%（高端） |
| 收入占比 | 21%（2023.10）→ 12%（2024.10） |
| 库存损失 | 55亿美元（H20） |
| 潜在损失 | 80亿美元（Q2预期） |
| 股价影响 | 禁令日跌7%，市值蒸发1800亿美元 |

### 2.4 黄仁勋的两难

**对美国政府的游说**：
- "华为的技术突破正在改写游戏规则"
- "伤害中国的事往往更严重伤害美国"
- "全球半数AI专家来自中国"

**对中国的示好**：
- 参加中国分公司年会（耍金箍棒）
- 体验华为三折叠屏手机
- 强调"中国是英伟达非常重要的市场"

**结果**：
- 左右为难，两边不讨好
- 鹰派批评他"危及国家安全"
- 中国市场被国产芯片蚕食

## 七、核心洞察

### 1. 禁令的悖论
> "美国的禁令亲手为英伟达在中国市场制造了一个最强大的竞争对手。"

- 封锁→华为崛起→英伟达失去市场→解禁清库存
- 技术封锁反而加速被封锁方的自主创新

### 2. 算力即权力
- 英伟达CUDA生态是护城河
- 但硬件性能差距在缩小
- 软件生态的迁移正在进行

### 3. 工程能力弥补工艺差距
- 国产芯片能效比落后约30%
- 但通过液冷、集群架构弥补
- "电力+工程能力"硬顶

### 4. 产业链重构
- 从全球化到区域化
- 中国建立"设计-制造-封装"全链条
- 85%国产化率（华为昇腾）

### 5. 时间窗口
> "推理侧闭环已跑通，训练侧闭环'只差光刻机'。再给中国2-3年时间..."

- 2025-2027是关键期
- EUV突破=完全自主
- 否则持续落后一代
