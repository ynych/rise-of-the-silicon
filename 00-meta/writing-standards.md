# 硅基编年史 - 写作规范与来源标注标准

## 一、来源可信度分级

每篇文档末尾必须包含"信息来源"章节，并使用以下标签：

| 标签 | 含义 | 使用场景 |
|------|------|---------|
| `[官方]` | 公司官方公告、财报、博客 | OpenAI官方博客、英伟达财报电话会议 |
| `[权威媒体]` | 知名科技媒体 | The Information、Reuters、Bloomberg、36氪 |
| `[多方交叉验证]` | 3个以上独立信源确认 | 融资额、人事变动 |
| `[单一信源]` | 仅一家媒体报道 | 需标注来源，如"据The Information报道" |
| `[推测]` | 基于公开信息的合理推断 | 人物心理、内部决策动机 |
| `[待核实]` | 存疑或正在确认的信息 | 需要后续核实补充 |

## 二、事实核查清单

发布前检查以下项目：

- [ ] 所有具体数字（金额、百分比、日期）是否有来源
- [ ] 人物引语是否标注出处（访谈、推文、演讲）
- [ ] 时间顺序是否准确
- [ ] 多方观点是否平衡呈现
- [ ] 技术术语是否准确（如区分训练和推理）

## 六、质量标准

### 必须避免的问题

1. **时间错误**：如"2023年5月政变"实际发生在11月
2. **人物混淆**：如将John Schulman和Jan Leike的角色搞混
3. **数据过时**：如使用2024年的市值数据描述2026年的情况
4. **来源不明**：如"据说""传闻"等模糊表述

### 加分项

1. **独家细节**：从一手访谈或内部人士获得的信息
2. **数据可视化**：时间线图、组织架构图、市场份额图
3. **对比分析**：中美对照、开源vs闭源对比
4. **预测验证**：对过往预测的回顾和验证
