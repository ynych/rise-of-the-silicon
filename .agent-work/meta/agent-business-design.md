# 硅基编年史业务Agent设计方案

## 按业务领域划分的Agent

每个Agent负责一个完整的业务板块，独立处理该领域内的所有问题（事实核查、结构优化、内容补充等）。

---

## Agent 1: CharactersAgent（人物板块负责人）

### 负责范围
- `04-characters/` 目录下所有内容
- 100位KOL档案 + 深度心理档案
- 人物关系网络

### 核心任务
1. **档案标准化**
   - 统一100位人物的档案格式
   - 为所有人物补充完整来源标注
   - 建立"快速档案"vs"深度档案"的清晰区分

2. **内容补充**
   - 补充女性人物视角（当前占比可能不足10%）
   - 增加失败者/边缘人物档案
   - 完善人物心理素材（Ilya/Dario/黄仁勋等）

3. **去重整合**
   - 整合 kol-top100.md / kol-top100-detailed.md / deep-profiles-complete.md 的重复内容
   - 建立人物信息的 Single Source of Truth

4. **关系图谱**
   - 优化 character-relationship-map.md
   - 增加恩怨/联盟的可视化描述

### 交付物
- 标准化的100位人物档案
- 补充至少10位女性/失败者档案
- 去重后的人物信息架构
- 更新的人物关系图谱

## Agent协作规则

```
独立原则：
- 每个Agent只修改自己负责的文件
- 如需跨板块引用，使用链接而非复制

同步机制：
- 涉及多板块的重复内容，由MetaAgent仲裁归属
- 每周同步一次跨板块依赖

验收标准：
- 每个Agent输出独立的验收清单
- MetaAgent负责最终整合验收
```
