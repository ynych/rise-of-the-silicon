## 写作规范

本项目遵循严格的非虚构写作标准：

1. **来源标注**：所有数据标注可信度分级 `[官方]` `[权威媒体]` `[多方交叉验证]` `[单一信源]` `[推测]`
2. **事实核查**：重大数字、日期、人物引语需二次验证
3. **平衡报道**：同一事件呈现多方观点
4. **统一格式**：人物档案、事件记录、分析报告使用标准模板

详见：`00-meta/writing-standards.md`

## 核心洞察

1. **技术演进是非线性的** - 从AlexNet到AGI，突破往往来自"意外"
2. **组织是创新的敌人** - 所有突破都来自"被遗忘的角落"
3. **开源是理想主义者的武器** - 不仅是技术选择，更是价值观选择
4. **人才战争本质是价值观战争** - 不是钱的问题，是对AI未来的不同想象
5. **芯片禁令的悖论** - 越禁替代越快，开源成为突破封锁的策略
6. **商业化必然牺牲安全** - OpenAI案例表明，IPO压力导致安全边缘化
