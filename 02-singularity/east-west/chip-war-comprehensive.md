# 芯片战争全景：美国禁令与国产替代

## 一、美国禁令时间线（2022-2026）

### 1.1 禁令时间线（2022-2026）

| 时间 | 事件 | 影响 |
|------|------|------|
| **2022年8月** | A100/H100被禁 | 英伟达失去高端市场 |
| **2023年10月** | A800/H800被禁 | "阉割版"也无法出口 |
| **2025年4月** | H20被禁 | 英伟达损失55亿美元库存 |
| **2025年5月** | 全球禁用昇腾 | 美国宣布在世界任何地方使用华为昇腾芯片都属违规 |
| **2025年7月** | H20解禁 | 特朗普政府恢复出口，但需审查 |
| **2025年12月** | H200出口获批 | 特朗普宣布允许H200对华销售，需支付25%"分成" |
| **2026年1月** | H200规则发布 | 商务部将审查从"推定拒绝"转为"逐案审查" |
| **2026年2月** | H200销售为零 | 商务部官员证实H200对华销售为零，国务院推动更严格限制 |

### 1.2 H20：妥协的产物

**技术参数**：
- 峰值算力：仅H100的15%
- 内存带宽：4TB/s（H100的约一半）
- 互联速度：降至H100的1/15

**黄仁勋的评价**：
> "H20非常适合中国市场，客户非常想要。"

**现实**：
- 专为中国市场设计，海外无竞争力
- 2025年4月禁令导致55亿美元库存损失
- 7月解禁被视为"清库存"策略

### 1.3 H200：政策反复的典型案例

**2025年12月突破**：
- 特朗普通过社交媒体宣布允许H200对华出口
- 附加条件：美国政府收取25%销售额"分成"
- 需在多部门（国务院、国防部、能源部）联合审查下逐案审批

**2026年1月规则细节**：
美国商务部工业与安全局（BIS）发布最终规则，将H200出口审查从"推定拒绝"（presumption of denial）调整为"逐案审查"（case-by-case review）：
- **技术门槛**：TPP低于21,000、DRAM带宽低于6,500 GB/s
- **产能限制**：对华累计出货量不超过美国本土出货量的50%
- **安全要求**：必须通过美国境内第三方实验室独立测试
- **客户审查**：需出具非军事用途承诺及完善的安全管理程序

**2026年2月僵局**：
- 美国商务部出口执法助理部长戴维·彼得斯（David Peters）在国会听证会上证实：**H200对华销售为零**
- 国务院坚持推动更严格限制，声称要"降低中国利用H200芯片损害美国国家安全的风险"
- 跨部门审查机制导致审批悬而未决
- 英伟达方面沮丧："国务院把事情变得非常困难"

**政策悖论**：
H200事件揭示了美国对华AI芯片政策的内在矛盾：
- **商务部/产业派**：希望通过技术输出抑制中国本土芯片产业，同时获取经济利益
- **国务院/鹰派**：担心任何先进芯片出口都会增强中国军事AI能力
- **结果**：政策反复损害美国企业利益，却未能阻止华为昇腾崛起

## 三、[华为](../../02-singularity/organizations/huawei-ascend-inside.md)的逆袭

### 3.1 昇腾系列演进

| 芯片 | 工艺 | FP16算力 | BF16算力 | 对比英伟达 | 发布时间 |
|------|------|---------|---------|-----------|---------|
| **910B** | 7nm | 256-376 TFLOPS | - | A100水平 | 2024年 |
| **910C** | N+2（等效7nm）| 640 TFLOPS | 800 TFLOPS | H100的80-96%，H20的完美替代 | 2025年Q1 |

| **950PR** | - | - | - | 互联带宽优于910C，内存略逊 | 2026年Q1 |
| **950DR** | - | - | - | 互联带宽、显存全面优化 | 2026年Q4 |

### 3.2 昇腾910C：国产替代的里程碑

**技术创新**：
- **双Die封装**：将两颗910B处理器集成到单一封装，AI核心从256个扩展至512个
- **Chiplet架构**：突破单芯片物理限制，实现算力跨越式提升
- **互联突破**：Scale Out扩展带宽与英伟达GB200持平，彻底突破国产芯片集群互联瓶颈
- **性价比**：单颗售价约2万元，仅为H100市场价的20%

**性能表现**：
- FP16算力：640 TFLOPS（接近H100的680 TFLOPS）
- BF16算力：800 TFLOPS
- 推理性能：达H100的60-80%
- 功耗控制：310瓦功耗条件下，算力密度较H100提升40%

**市场响应**：
- 2025年5月开始大规模出货
- 主要客户：阿里巴巴、腾讯、字节跳动、百度等互联网巨头
- 订单火爆导致涨价：新订单涨幅接近40%

### 3.3 昇腾920：下一代突破

**核心规格**：
- **工艺**：中芯国际6nm（N+3节点）
- **算力**：900+ TFLOPS（BF16），超越H20（148 TFLOPS）约6倍
- **内存**：HBM3模组，4000 GB/s带宽
- **接口**：支持PCIe 5.0及下一代高吞吐互联协议

**架构优化**：
- 针对Transformer和MoE模型深度优化
- 训练效率比910C提升30-40%
- 增强张量操作加速器

**战略意义**：
- H20被禁后仅一天，华为即宣布920计划
- 明确对标：填补H20留下的市场空白
- 供应链"内循环"：从核心技术到生产制造力求自主可控

### 3.4 市场份额变化

### 3.5 CloudMatrix 384：集群层面的超越

- **架构**：384颗昇腾910C芯片构建
- **算力密度**：比英伟达NVL72提升50倍

- **地位**：目前国内唯一正式商用的大规模超节点

这是典型的"群殴"模式——单芯片性能不及英伟达，但通过系统层面的创新，组成更大规模集群弥补差距。

## 四、[中芯国际](../../02-singularity/organizations/huawei-ascend-inside.md#四制造工艺进展与华为绑定)：制造端的突围

### 4.1 工艺进展与华为绑定

| 工艺 | 等效节点 | 状态 | 良率 | 主要客户/应用 |
|------|---------|------|------|--------------|
| **14nm** | 14nm | 量产 | 99.8% | 推理芯片、成熟制程 |
| **N+1** | 等效10nm | 量产 | 95%+ | 中低端AI芯片 |
| **N+2** | 等效7nm | 风险量产 | 90%+ | **昇腾910B/910C** |
| **N+3** | 等效6nm | 试产 | - | **昇腾920** |
| **N+4** | 等效5nm | 研发中 | - | 下一代AI芯片 |

### 4.2 技术路径：DUV多重曝光的坚持

**核心挑战**：
- 无法获得EUV光刻机（受美国主导的瓦森纳协定限制）
- 必须使用DUV（深紫外光刻机）通过多重曝光实现等效先进制程

**N+2工艺（等效7nm）技术细节**：
- 基于DUV的**双重曝光**技术（Double Patterning）
- 晶体管密度：约100-120百万个/平方毫米
- 功耗性能比14nm提升约35%
- **成本**：比台积电同等级工艺高约30-50%
- **良率挑战**：多重曝光增加工艺复杂度，良率提升难度大

**N+3工艺（等效6nm）突破**：
- 采用**三重曝光**技术（Triple Patterning）
- 晶体管密度：120亿个（昇腾920）
- 晶体管密度较上一代提升约50%
- 支持更高性能的HBM3内存接口

### 4.3 产能扩张与供应链

**产能数据**：
- 14nm产能：20万片/年（2025年）
- 7nm（N+2）月产能：3.5万片（2025年）
- **2026年目标**：7nm产能翻倍至7万片/月

**国产化率**：
- 核心设备国产化率：超60%
- 关键材料（光刻胶、高纯化学品）：国产化率40-50%
- 目标：2026年核心环节国产化率达到70%

### 4.4 合作生态

**与华为的绑定关系**：
- 昇腾910B/910C：N+2工艺独家供应
- 昇腾920：N+3工艺独家供应
- 合作模式：联合研发、产能锁定、风险共担

**与其他客户**：
- 寒武纪思元590：部分采用N+2工艺
- 其他国产AI芯片设计公司：逐步导入

### 4.5 挑战与瓶颈

**技术瓶颈**：
- **EUV光刻机**：完全无法获得，限制进一步微缩
- **良率爬坡**：N+2/N+3良率仍低于台积电同等级工艺
- **成本压力**：多重曝光导致单位成本上升

**供应链风险**：
- 部分关键设备（刻蚀机、薄膜沉积设备）仍依赖进口
- 高端光刻胶由日本厂商主导
- 地缘政治风险可能导致设备维护中断

## 七、核心洞察

> "美国的禁令亲手为英伟达在中国市场制造了一个最强大的竞争对手。"

- 封锁→华为崛起→英伟达失去市场→解禁清库存

- 英伟达CUDA生态是护城河
- 但硬件性能差距在缩小
- 软件生态的迁移正在进行

- 国产芯片能效比落后约30%
- 但通过液冷、集群架构弥补
- "电力+工程能力"硬顶

### 4. 产业链重构
- 从全球化到区域化
- 中国建立"设计-制造-封装"全链条
- 85%国产化率（华为昇腾）

### 5. 时间窗口
> "推理侧闭环已跑通，训练侧闭环'只差光刻机'。再给中国2-3年时间..."

- 2025-2027是关键期
- EUV突破=完全自主
