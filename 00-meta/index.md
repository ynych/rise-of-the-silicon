## 🔧 写作规范（S3修复：版本标记统一）

### 文档命名规范

```
# 新规范（2026-03-09起统一使用）
- 主文档：kebab-case.md
- 迭代版本：文档名-v1.md, 文档名-v2.md（保留历史）
- 废弃版本：移到 archive/ 目录或标注 [DEPRECATED]

# 示例
correct:   agi-technical-landscape.md
correct:   agi-technical-landscape-v1.md (历史版本)
wrong:     AGI_Technical_Landscape_v2_final.md
wrong:     agi技术路线-20260309-迭代2.md
```

### 文档头部模板

```markdown
# 标题

> 
> 文档路径：`路径`
> 创建时间：YYYY-MM-DD
```

### 去重原则
1. **Single Source of Truth**：每个主题只有一个主要文档
2. **引用而非重复**：其他文档使用相对链接引用
3. **摘要+链接**：必要处写2-3句摘要，链接到完整文档
