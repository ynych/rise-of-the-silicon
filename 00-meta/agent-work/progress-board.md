## 协作评审阶段（准备启动）

### 阶段1: 成果自述

- 完成了什么
- 关键发现/洞察
- 如何支撑整体目标

### 阶段2: 上下游质疑
| 质疑方向 | 质疑方 | 被质疑方 |
|---------|--------|---------|
| 事件vs组织反应 | TimelineAgent → OrgsAgent | 重大事件是否反映组织变化？ |
| 人物vs组织 | CharactersAgent → OrgsAgent | 人物决策是否符合组织逻辑？ |
| 技术突破vs时间线 | TechRoutesAgent → TimelineAgent | 技术节点是否准确？ |
| 地缘vs公司策略 | GeoAgent → OrgsAgent | 地缘压力如何影响公司决策？ |
| 未来vs技术路线 | AGIEraAgent → TechRoutesAgent | 预测是否基于现有技术？ |

质疑清单:
- 是否揭示了重大事件？
- 预测依据是否充分？
- 是否提供了"认知爽点"？
- 内容是否矛盾？

### 阶段3: 整合对齐
MetaAgent主导，统一:
- 预测置信度标准
- 解决内容矛盾
- 确保叙事连贯性

### 阶段4: 迭代完善
根据质疑反馈，各Agent修改自己的板块
