## 跨板块引用规则

**你是时间节点的Single Source of Truth**

当其他Agent需要引用时间/事件时：
- 只提供事件名称 + 日期
- 提供链接到时间线
- 禁止在其他板块重复完整事件描述

示例:
```markdown
[2023年11月17日的OpenAI政变](../00-meta/timeline-v2-iteration2.md#2023-11-17)...
```
