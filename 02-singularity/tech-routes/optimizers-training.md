## 核心洞察

大模型训练是"高风险工程"——一次GPT-4级别的训练耗资数千万美元，失败意味着巨大损失。**优化器**决定了训练能否收敛、收敛速度、最终性能。从Adam到AdamW，从固定学习率到余弦退火，从单精度到混合精度，每一个细节都可能决定训练的成败。这是一门工程艺术，也是大模型公司的核心know-how。

## 优化器演进史

### SGD：最基础的起点

```
θ = θ - lr × ∇L(θ)
```

**问题**：
- 学习率难调
- 不同参数需要不同学习率
- 容易陷入局部最优

### Adam：自适应学习率

```
m_t = β₁ × m_{t-1} + (1-β₁) × g_t        # 一阶动量（动量）
v_t = β₂ × v_{t-1} + (1-β₂) × g_t²       # 二阶动量（梯度平方）
m̂_t = m_t / (1-β₁^t)                      # 偏差修正
v̂_t = v_t / (1-β₂^t)
θ = θ - lr × m̂_t / (√v̂_t + ε)
```

**优势**：
- 自动调整每个参数的学习率
- 适合稀疏梯度
- 几乎成为深度学习标配

### AdamW：权重衰减修正

**Adam的问题**：L2正则化和权重衰减不等价

**AdamW的修正**：
```
# 权重衰减独立进行
θ = θ - lr × weight_decay × θ    # 权重衰减
θ = θ - lr × m̂_t / (√v̂_t + ε)     # Adam更新
```

**影响**：成为大模型训练的标准优化器

### 其他优化器

| 优化器 | 特点 | 适用场景 |
|--------|------|----------|
| **Adafactor** | 内存优化版Adam | 内存受限 |
| **Lion** | 符号更新，内存友好 | 大模型训练 |
| **Muon** | 正交化梯度 | 深层网络 |
| **SGD+Momentum** | 最终微调 | 精细调优 |

## 学习率调度：火候的掌控

### 关键阶段

```
学习率
  ↑
  │      ╭────╮
  │     ╱      ╲_______
  │    ╱  稳定期  ╲
  │___╱            ╲___
  │  预热            衰减
  └──────────────────────→ 训练步数
```

### 预热（Warmup）

**原因**：训练初期梯度不稳定，大学习率导致发散

**做法**：
- 前N步（通常1%-2%的总步数）
- 学习率从0线性增长到目标值

### 稳定期

**恒定学习率**或**小幅衰减**

### 衰减（Decay）

**余弦退火（Cosine Decay）**：
```
lr_t = lr_min + 0.5 × (lr_max - lr_min) × (1 + cos(π × t / T))
```

**优点**：
- 平滑衰减
- 有助于收敛到更好的局部最优

### 其他调度策略

| 策略 | 公式 | 特点 |
|------|------|------|
| **Step Decay** | 每N步乘以系数 | 简单直观 |
| **Exponential** | 指数衰减 | 快速收敛 |
| **Polynomial** | 多项式衰减 | 灵活可控 |

## 训练稳定性：避免灾难

### 常见训练灾难

| 问题 | 现象 | 解决方案 |
|------|------|----------|
| **损失爆炸** | Loss突然变成NaN | 梯度裁剪、降低学习率 |
| **损失停滞** | Loss不下降 | 检查数据、调整学习率 |
| **过拟合** | 训练Loss↓，验证Loss↑ | Dropout、早停、更多数据 |
| **模式崩溃** | 输出单一重复内容 | 数据多样性、温度调整 |

### 梯度裁剪（Gradient Clipping）

```
if ||g|| > threshold:
    g = g × (threshold / ||g||)
```

**作用**：防止梯度爆炸

### 混合精度训练

**FP16/BF16 + FP32**：
- 前向/反向：FP16（省显存、加速）
- 权重更新：FP32（保精度）
- 损失缩放：防止FP16下溢

**效果**：
- 显存节省50%
- 速度提升2-4倍

## 大规模训练的特殊挑战

### 分布式训练的优化器状态

**问题**：Adam需要维护2倍于参数量的状态（m, v）

**解决方案**：
- **ZeRO**：分片优化器状态到多卡
- **Adafactor**：因子化二阶矩，减少内存

### 学习率与Batch Size的关系

**线性缩放规则**：
```
lr_new = lr_base × (batch_size_new / batch_size_base)
```

**原因**：更大的batch需要更大的学习率保持更新幅度

### 不稳定性的检测与恢复

**监控指标**：
- Loss曲线（突然上升/NaN）
- 梯度范数
- 学习率

**自动恢复**：
- 检测到异常 → 回滚到上一个checkpoint
- 降低学习率 → 继续训练

## 超参调优：炼丹的艺术

### 关键超参

| 超参 | 典型值 | 影响 |
|------|--------|------|
| **学习率** | 1e-5 ~ 1e-3 | 收敛速度、最终性能 |
| **Batch Size** | 1M-10M token | 训练稳定性、速度 |
| **Warmup比例** | 1%-2% | 初期稳定性 |
| **Weight Decay** | 0.01-0.1 | 正则化强度 |
| **β₁, β₂** | 0.9, 0.999 | Adam动量系数 |

### 调优策略

1. **网格搜索**：小范围尝试
2. **学习率范围测试**：找最优学习率
3. **经验法则**：参考相似模型配置

## 结论

优化器和训练稳定性是大模型训练的"内功"。好的优化策略能让同样的模型和数据达到更好的效果，而一次失误可能导致数百万美元的损失。在这个领域，经验比理论更重要，每个大模型团队都有自己的"炼丹秘籍"。
